# 7C-QA1｜iPhone 與 iPad 實機取證

目前四格均待測。先用製作人現有 iPhone 與 iPad，記下型號、iOS／iPadOS、電池／低耗電模式、可用空間、畫面方向、Wi-Fi／網路狀況及入口。兩個固定 SHA 由 QA 提供對應 HTTPS 子路徑的版本網址或在授權環境本機提供；核對實際入口版本後再比較。Safari 和主畫面各自保留結果。取證用隔離測試資料與存檔副本。

1. **先驗證入口。** Safari 從指定 HTTPS 入口開始。主畫面由已核准的 App 入口「加入主畫面」，從圖示開啟，確認沒有 Safari 工具列並記錄實際起始與森林 URL。PR #39 的森林預覽是分開的入口；若從主畫面走工作台後跳到 Safari、缺同路徑的獨立模式或入口版本無法求證，記為受阻。正式候選更新前後，同樣核對 SHA、存檔與實際模式。
2. **冷暖與首次繪製。** 同裝置與模式做三組冷／暖，冷用隔離新快取或全關閉後冷程序，確切寫明是哪一種。勿清除個人遊戲資料。每組先按開啟網址／圖示，等角色可移動，用搖桿短試。暖為保留同入口資料，回首頁或重開後再試。短螢幕錄影只開在這段，從開啟動作至首次遊戲畫面、再至第一次可見動作各取時間。打開「霧竹林・啟動紀錄」，貼上既有階段日誌；日誌起點是入口 HTML 計時，與影片起點分別登錄。需要時記錄 20 秒內的失敗狀態與重新載入。完成一遍後可把錄影交給 QA 統一取幀。
3. **同一趟驗操作。** 走分岔、瀑布折返、橋、神龕與東側回南口。PR #39 用已存在的西側寶箱和回程作對照。左右橫向試雙指搖桿加揮劍或閃避（各五次），留意安全區、黏住的操作及按鈕遮蔽。轉直向確認暫停，再轉回；切背景 10 秒再進場。候選在疾風交流拒絕收音一次，走輔助、重訪確認可完成，暫停／返回沒有殘留收音。記錄失敗、回復與原因；開啟減少動態及靜音各檢一輪預警。弱網、斷線、恢復及已安裝 PWA 更新另記實際條件。
4. **15 分鐘及三趟回訪。** 用相同路線合併遊玩穩定性、三次重訪、碰撞和重試。每次回南入口靜置 30 秒再繼續。記錄黑屏、載入、卡住、任何可見頓挫或重載及前後存檔。候選另在守護者戰敗、退出及重試各一次。建議先做兩部 Safari 的快速入口與觸控煙測，再於預定彩排分批完成四格，避免反覆走相同路線取同一證據。
5. **選用儀器。** 有可配對的 Mac Safari Web Inspector 時由 QA 協助取樣。幀時間用時間線量前景可操作窗口，分開記錄旋轉、背景及導航。若能取得一致記憶體指標，於同一鏡位三次靜置後取樣並記類型，每次回同一計時點。螢幕錄影可估算可見觸控起點到第一次動作的上界，須有可見觸點或同步外部攝影並標幀率。若儀器不支援或影響互動，保留觀察並將相應數值標「待取證」。解碼估算、JS heap、頁面程序及 GPU 記憶體分開記錄。

日誌／影片檔只需交下表與問題片段。每輪每格記錄一列，冷暖三組可一列並排。兒童試玩取證另循展示計畫，先小樣本也需同意，實際樣本未到 5 位時五童門檻維持待測。
