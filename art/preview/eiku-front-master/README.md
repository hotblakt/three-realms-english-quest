**判定：可作角色設計參考，正式遊戲貼圖暫不採用。**

[原始候選圖](../../reference/eiku-front-master-candidate.png) 是 1199 × 1312 的 8-bit RGB PNG。沒有 alpha 或透明色資料，背景為實際的近白色像素，並非透明或棋盤格。原始檔未重編碼，SHA-256 為 `880878ef463353a7d51b2190f323072c1fc62a749026ccc62da1f078c780050e`。

## 檢視方法

執行 `npm run dev`，開啟 Vite 網址下的 `/art/preview/eiku-front-master/`。左圖取自實際 Phaser 角色的起始正面影格；右圖使用[透明候選格](eiku-front-idle-preview.png)，以正式比例 2/3 顯示。可切換竹綠、深色及淺色背景，並放大或顯示腳底定位線。這個頁面與候選格不會進入正式建置。

候選格使用 ImageGen 從原圖分離背景，裁出主體和留白，再等比例縮小並定位。自動分離可能重建少量輪廓像素，因此此格是衍生預覽，原檔仍作比對基準。

## 正式出圖前需修正

1. 從原始圖層輸出帶乾淨 alpha 的角色，或人工校正髮尖、圍巾、刀柄與鞋底，清掉散點並檢查深淺底的邊緣。
2. 依俯視遊戲鏡頭重畫或精修縮圖，強化頭部與肩部剪影、壓短腿部並簡化衣紋。先在 62–66 px 站姿高度及 2/3 顯示比例下驗收臉與護額。
3. 這張主視覺可指導其他方向的配色、道具與服裝，但仍需獨立製作側、背方向與動作影格。沿用 [正式圖集規格](../../production/eiku/README.md) 的 96 × 96 格和 `(48, 72)` 原點，逐方向核對佩刀、圍巾與接地點。
