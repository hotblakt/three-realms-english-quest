# 隱竹村 2.5D 對照

以下為 Chromium 在相同遊戲座標與視窗尺寸取得的畫面。對照圖左為 6A 前，右為 6A 後。

- [村莊入口前後對照](spawn-before-after.webp)。影空腳底增加柔和接地陰影，燈籠的光圈改成漸層，光暈停留在地景層。
- [屋瓦遮擋前後對照](roof-before-after.webp)。角色在屋後時只淡化屋瓦，牆面仍清楚。走離屋簷後屋瓦恢復不透明。
- [竹枝前景遮擋](bamboo-occlusion.webp)。畫面左上偏中的影空由竹枝局部遮住。穿過竹根的深度平面後，角色會畫在竹枝前方。

可穿越的竹枝使用同一圖集和各自的根部深度。村莊邊界外的竹林仍合成遠近兩層。鳥居的基座留在地表，架體按柱腳深度繪製。行動觸控版最多有 5 個風葉與風痕物件，燈籠維持靜態柔光，偏好減少動態時停播環境風效。現有碰撞、攻擊與任務規則沿用原設定。

Chromium 已驗證前後移動、竹枝繪製順序、屋瓦透明度恢復、碰撞、對話及模擬 iPad／iPhone 橫向版面。實機 Safari 的 GPU 表現和長時間運作仍待驗收。
