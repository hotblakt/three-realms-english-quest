# 影空 2.0 南向單格驗收

[原始主圖](../../reference/eiku-v2-south-master.png) 是 1254 × 1254 的 8-bit RGBA PNG，SHA-256 為 `8f5c9facad63ff8ac1c0bd751308b5aeb4e1ec0623c904ad245de2364f3a68c2`。alpha 範圍為 0–255，主圖沒有烘入棋盤格或實色背景。部分外圍像素的 alpha 為 1，鞋底周圍另有半透明橢圓地影。

| 項目 | 結果 | 觀察 |
| --- | --- | --- |
| 透明度 | PASS（候選格） | 96 × 96 RGBA，有真透明留白。主圖的橢圓陰影另行移除。 |
| 比例 | PASS | 沿用 2.0 的頭身、姿勢和配色，以同一倍率縮小，未拉伸。 |
| 腳底對齊 | PASS | 可見輪廓（alpha > 32）外框是 `[31, 8, 67, 72)`，站姿高 64 px；雙腳接地像素的水平中點在 x=48，接地邊界 y=72。髮尖、圍巾與刀柄均在格內。 |
| 地面陰影 | PASS | 成品 y=72 以下全部透明；鞋間底部只有 0–2 的重取樣 alpha，深淺底和村莊底均無可見橢圓影。 |
| 邊緣 | PASS（單格預覽） | 草綠、深色與淺色底上未見大面積白邊、散點或鞋底剪斷。縮圖上仍應收整髮尖與圍巾的低對比邊。 |
| 遊戲尺度可讀性 | FAIL（正式美術門檻） | 以 2/3 倍約 43 遊戲單位高。髮型、臉部明暗與藍圍巾可辨；眼睛、護額風紋與刀鍔細節在村莊紋理上變得很小，深色底的圍巾尾及刀柄辨識度偏低。 |

[衍生候選格](eiku-v2-south-idle-preview.png) 保留原圖的角色顏色與形狀。先用 ImageGen 移除地影，取鞋底附近的 alpha 遮罩與原圖 alpha 交集，其餘角色像素沿用原圖；再清理極低 alpha、等比例縮圖及放入格線。候選資產僅供[美術工作台](https://hotblakt.github.io/three-realms-english-quest/art-workbench/)檢視，可切回含地影的原始主圖。

**方向設計建議**：以此主圖作為北／西／東向的造型參考，沿用頭身比、髮型、護額、靛藍圍巾、配色與佩刀位置。各方向應獨立繪製，明確保留刀柄與圍巾的前後及左右關係。正式出圖時放大護額的淺色區塊並簡化風紋、提高眼部明暗與圍巾和刀柄的輪廓對比，避免靠高解析衣紋辨識角色。驗收時應逐方向比對村莊底、深底與腳底原點，並補齊[正式圖集規格](../../production/eiku/README.md)所列動作。
