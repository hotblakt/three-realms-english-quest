# 影空 2.0 四向動作

從美術工作台開啟霧竹林，「FrameSprite 自動方向」使用四向跑步和待機。東、西、南停下後按 K 或「施法」，北向缺少合格施法，維持待機。揮劍、閃避和移動可中斷施法，施法依原規則只提供視覺回饋。鏡頭預設 1.3 倍，角色高度 207%，速度、碰撞和傷害規則沿用既有設定。診斷素材留在獨立選項組。

## 載入與記憶體

首屏沿用 256 px 東向跑步暖載，其他方向和解析度在選取、移動或施法時載入。下載未完成時沿用站姿，物理可照常運作。選擇的解析度適用於即時遊玩與逐格檢閱。已載入的變體在本頁 Phaser 快取保留至重新整理，切過多個方向或解析度會累加。

- 北、西跑步每張 256 px 解碼約 3 MiB，384 px 各約 6.75 MiB。
- 新待機和施法每張 256 px 約 4 MiB，384 px 約 9 MiB。
- 這批七組新動作全在 256 px 各看一次會累加約 26 MiB。若兩種解析度全部載入約 84.5 MiB，另計舊動作、環境與 GPU 副本。這些是圖集長寬乘以四位元組的估算。
- 低記憶體裝置建議保留 256 px。實機 Safari 的解碼／記憶體峰值仍待驗收。

## 真機驗收清單

1. iPad 與 iPhone 橫向 Safari 和獨立 PWA，檢查搖桿、按鈕點按範圍與安全區。
2. 依序朝四向移動與停下，逐格核對足底、跑步接縫及首次載入是否掉幀。
3. 東、西、南施法後用轉向、揮劍與閃避中斷。北向只維持站姿或待機。
4. 分別來回切 256／384 px、停格與復播，觀察 Safari 記憶體。再回第一章驗證遊戲及英文學習。
