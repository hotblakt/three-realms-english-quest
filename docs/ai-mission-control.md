## 登錄、生命週期與分工

[任務登錄 JSON](../mission-control/tasks.json) 是任務、優先序、基準版本及量測的唯一來源。GitHub 觀測值以衍生快照呈現。任務 ID 永久保留，里程碑可包含多個任務。更新時保留歷史，加入含日期與證據的新狀態。分支或 PR 不足以判定 AI 已開始執行。標成執行中需留可追溯證據。首次匯入歷史可從當時已知狀態開始，未知步驟與時間不補造。

基本流程為待辦、可排程、已交接、執行中、待審閱、待製作人驗收、完成。遇阻礙應記錄原因，解決後可回到待辦或可排程。修正後重審回到可排程，完成和取消為終止狀態。未知分支、SHA、PR 與部署使用 `null`。

| 角色 | 作業 |
| --- | --- |
| 製作人 | 核准目標、優先序、支出、驗收與發布。 |
| ChatGPT | 拆分可驗收任務，核對依賴及衝突，準備下一項提示。 |
| Codex | 在獨立分支開發，回報實測及證據。 |
| Work | 核對狀態、審查及授權，依現有發布協定辦理。 |
| ChatGPT Images／FrameSprite | 依核准規格製作美術與動畫，留下成本與驗收證據。 |

排程器只推薦依賴已完成的可排程任務。已交接與執行中占用名額，上限為三條製作工作流加一條發布／品檢工作流。Codex 作業需獨立分支和寫入範圍，相同分支或重疊檔案／目錄會擋掉並行建議。登錄也拒絕已占用中的衝突。一切實際交接前仍需核對分支、檔案差異及授權。控制台無法限制工具在外部直接改檔。

## 唯讀同步與隱私

`node scripts/sync-mission-control.mjs` 透過 REST GET 讀定址公開遊戲庫。核對登錄的分支、PR head／merge SHA、同 head 和 PR 的 CI 與品質門檻、同合併 SHA 的 `main` Pages 工作。查不到可對上的證據時保持未知。只輸出驗證過的 ID、時間、狀態和 SHA。瀏覽器讀同源快照，連結由固定公開庫和 ID 產生。API 內容、帳號、任意 URL、憑證和私有素材不進產物。登錄欄位限列，建置拒絕常見敏感字串。公開資料仍需人工審閱，私人資料留在私有工具。

現有 Pages 建置在上傳前生成快照，使用該工作臨時權杖的 `contents: read`、`actions: read`、`pull-requests: read`。部署工作與 repository 設定沿用原狀。API 受限、網路失敗或限速留下未知／部分結果，遊戲仍可建置。快照超過 24 小時標為過期。當次 Pages 建置尚未部署，無法提前顯示同一輪成功。下一次獲授權建置才會更新公開快照，沒有獨立定期發布。在此執行環境 API 回傳 Forbidden，已驗證無法讀取時的備援與模擬成功流程，GitHub Actions 實際權限待首次授權發布確認。

## 使用與手動交接

用 `npm run dev` 開啟 `/mission-control/`，或用正式建置預覽 GitHub Pages 子路徑。這是獨立於遊戲的 iPhone 直向／iPad 頁面。「下一步」顯示單一分配給製作人的優先行動。展開提示可複製，剪貼簿權限不足時可選取並使用裝置的複製功能。拿到實際結果後再更新 JSON。

目前自動化涵蓋資料驗證、去重、依賴和並行建議、下一步選擇及唯讀快照。AI 派工、支出核准、裝置驗收、合併及發布仍由人工交接。未假定 ChatGPT、Codex 或 Work 可透過 API 相互派工。後續須有可驗證的 API、授權與稽核才評估整合。[發布協定](release-management.md)

使用外部 Playwright 執行 `node scripts/check-mission-control-mobile.mjs` 可回歸手機排版、複製、過期及資料清理。以 `PLAYWRIGHT_MODULE` 和 `CHROMIUM_PATH` 指定本機工具，無需更改遊戲依賴。

## 7A-3｜PR #40 發布門檻修正

製作人授權 **Pages 建置工作**的短期 `GITHUB_TOKEN` 使用 `contents: read`、`actions: read`、`pull-requests: read`。快照收集步驟只對固定公開遊戲庫發出 REST GET。部署工作仍只有 `pages: write` 與 `id-token: write`，用途為既有 Pages 發布。儲存庫設定與保護規則照舊，權杖內容不進入日誌或公開產物。

原始重現是在兩個分支同時排入 `mission-control/main.mjs` 與 `mission-control//main.mjs`，兩者均被接受。登錄與排程現在使用同一個路徑比較鍵。支援儲存庫相對路徑，以 ASCII 英文字母、數字、點、底線、連字號及正斜線組成。重複及尾端斜線會合併，單獨的 `.` 段落會移除。保留 `.github` 等隱藏目錄。拒絕所有 `..` 段落、絕對／磁碟路徑、反斜線、萬用字元、空白、空範圍和尾端點號。所有大小寫變體視為同一位置，目錄與子項也會衝突。比較鍵僅用於排程，實際檔名仍以 Git 為準。符號連結或外部工作區別名需在交接時另行核對。

7A-1 登錄既有 **PR #40** 及來源分支 `feat/ai-mission-control-v2-foundation`，保留待審閱。收集器核對 PR 編號、來源庫、來源分支與目的分支。未合併的 PR 不採用預先產生的測試合併 SHA，也不判定已部署。

公開快照只會在下一次獲授權的 `main` Pages 建置生成並隨該次產物發布，包括現有的手動工作流程觸發方式。可在本機執行收集器核對輸出，這不會更新 Pages。同一輪部署的完成結果可能不在自己的快照中。超過 24 小時顯示過期，無資料或讀取受限時顯示未知。這次沿用建置時同步，沒有新增輪詢或定期發布。此環境的 API 讀取仍受限，真實 Actions 端到端更新待授權發布確認。
