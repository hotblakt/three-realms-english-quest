## 可重建的離線產物

使用已驗證的私有 ZIP 及專案 Python 測試環境執行：

```sh
python scripts/prepare-forest-batch-b.py /path/to/forest-v2-batch-b-candidates.zip /tmp/forest-batch-b
```
