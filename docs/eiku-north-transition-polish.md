# 影空跑停轉場的可見身高校正

## 原因與修正

原 120 ms 轉場以整張畫格的顯示邊長直接插值。換成較高的待機姿勢時，第一格仍套用前一張跑步圖的顯示邊長。北向跑步原本經核准放大為 114%，所以待機格先被放大，再縮回原尺寸。反向切回跑步時，同樣的畫格高度差可能產生先縮後大的感覺。

現在依上一張已顯示畫格的身體高度起算。新姿勢立即出現，使用其身體高度反推相同可見高度所需的等比縮放，然後在原 120 ms 內平滑收斂到核准的顯示尺寸。過程如果再次轉向或跑停，會由當前高度接續。每張核准的 Run/Idle 格使用既有 256 px 頭頂到靴底量測，排除圍巾、佩刀及特效，再將比例用於兩種解析度。以當前畫格為準可保留原有屈膝、落地、起伏。診斷、施法與減少動態預設的直接切換則沿用原圖的核准尺寸。

## Chromium 逐格量測
