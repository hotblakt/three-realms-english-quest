## 場景結構

- `placement.ts` 統一繪製原點、分層、方向、色調與透明度，提供背景竹叢、腳點排序物件、光斑、地標和瀑布位置。樹叢較疏的位置沿用現有竹材變體，添加用於節奏的低矮灌木與深色背景輪廓。原有碰撞仍使用舊樹叢的根部與尺寸，視覺疏密可獨立調整。
- `terrain.ts` 以同一張半解析畫布合成濕苔、透光亮地、落葉與曲線路底，再放原有石片。落葉與光地皆使用固定配置，每次進場畫面一致。
- `creek.ts` 讓左右溪岸各自隨地形起伏，使用蒙版柔化貼圖外緣並保留溪心紋理。沿岸用既有岩石和灌木打散接縫。水紋沿溪道往下游淡出，兩處飛瀑沿用橋圖內的既有瀑面，再加少量流線。未來可在瀑布配置加入獨立瀑面素材。
- `vegetation.ts` 管理遠景、前後遮擋物和低層薄霧。少量過濾日光從現有空地落入，可用原有環境光設定關閉。減少動態時停用環境動畫，保留靜態光影。
- 古鳥居、木橋、藏寶路與風靈神龕的場景座標、顯示層和互動仍可分別配置。神龕目前沿用靈霧和提示。後續美術可用相同座標與原點替換，再依需求增加獨立遮擋層。

## 待製作的正式素材

| 優先 | 需要的素材 | 交付要點 |
|---|---|---|
| 1 | 溪水、左右濕岸、岸石、轉彎與瀑布組 | 可銜接平鋪的水面，獨立柔邊與短瀑面。保留水流方向、岸腳和橋頭接縫參考。 |
| 2 | 竹梢、竹根及灌木變體 | 按腳點與樹冠分層的透明部件，至少具疏、中、密三種剪影。提供遠景冷色變體，留出主路和地標視線。 |
| 3 | 濕苔、落葉、踏石與溪邊泥地 | 提供可無縫平鋪底圖、局部貼花和過渡邊。暗處維持可辨路徑。 |
| 4 | 橋欄、古鳥居與風靈神龕 | 石座、橋面與前欄分層。交付柱腳、原點與前景遮擋參考，保留隱路和神龕入口的視線。 |

新版未加入外部美術。瀑面和橋欄仍耦合在原橋圖，岸水材質近看可見重複，較古老的 Safari 若忽略 Canvas 2D `filter`，岸邊會較硬。視覺岸線允許少量裝飾性偏移，實際碰撞沿用既有河道。

## 整合與行動成本

已納入 PR #28，基準為 main 的 d15f76f。合併時複核 ForestScene.ts。環境模組負責地景與地標，角色更新區段保留 main 的載入閘門、動作與腳底定位。影空四向跑步和待機在開放輸入前準備，施法在背景載入。預設 256 px、207%、1.3 倍與 120 ms 轉場均沿用。跑步比例東 100%、西 100%、北 114%、南 95%。沒有新增 16 MiB 快取上限或淘汰流程，必要 Run/Idle 圖集保留至離開頁面。

Chromium 讀取已註冊紋理的像素尺寸，以下以 RGBA 長 × 寬 × 4 估算。GPU 副本、瀏覽器、緩衝區與解碼暫存另計。

| 紋理組合 | RGBA 估算 |
|---|---:|
| 基本場景與角色（尚未計入動畫圖集及衍生站姿） | 10.96 MiB |
| 256 px 必要 Run/Idle 與基本場景 | 36.71 MiB |
| 256 px 加背景 Cast 與基本場景 | 48.71 MiB |
| Chromium 走過溪岸與探索點後，含一張衍生站姿 | 48.96 MiB |
| 384 px 必要 Run/Idle 與基本場景 | 68.90 MiB |
| 384 px 加背景 Cast 與基本場景 | 95.90 MiB |
| 主動切換後兩版均留在本頁，連同基本場景 | 約 133.65 MiB |

256 px 必要動畫下載 2,518,016 B，加現有環境和站姿 WebP 約 3,626,092 B，另計 JS/CSS。溪床、地表與日光紋理的環境增量約 0.55 MiB。診斷圖集與額外站姿按需加入。主動切換解析度會累加快取，Safari 實機的記憶體峰值仍待測。若下一階段調整快取，需保留所有必要動作，優先評估已離開的診斷紋理與使用完畢的選用解析度。

## 整合驗收

- 模擬 iPhone 橫向限速（400 ms 延遲、下行 2,000,000 B/s）且停用 HTTP 快取，分別冷啟動四次。開放操作約 4.56–5.05 秒，每個方向第一次按鍵到觀察到跑步格為 2.2–5.4 ms，均早於首個可觀察的位移。此為 Chromium 動畫幀取樣。
- 模擬 iPad 驗證觸控、北向跑停、原點不變及切換 384 px 時可先使用原解析度。減少動態測到場景環境 tween 為零。
- 桌面過橋、溪岸碰撞、寶箱、神龕提示與回程捷徑均完成瀏覽器檢查。原村莊開發預覽驗證長老對話、六堂課、輔助練習、重新載入存檔，以及 PWA manifest 和圖示。Chapter 1、英文學習、存檔及 PWA 程式與 main 相同。
- 下游素材製作可依 [霧竹林 2.0 正式素材規格](misty-bamboo-forest-v2-production-spec.md)。其中有每套原點、遮擋、無縫與驗收要點。本次未產生新美術。
