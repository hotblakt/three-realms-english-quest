前後比較為同一位置和攝影機，左為原本，右為新版。角色、地圖尺寸、橋面開口、障礙物和探索點維持既有設定。

## 場景結構

- `placement.ts` 統一繪製原點、分層、方向、色調與透明度，提供背景竹叢、腳點排序物件、光斑、地標和瀑布位置。樹叢較疏的位置沿用現有竹材變體，添加用於節奏的低矮灌木與深色背景輪廓。原有碰撞仍使用舊樹叢的根部與尺寸，視覺疏密可獨立調整。
- `terrain.ts` 以同一張半解析畫布合成濕苔、透光亮地、落葉與曲線路底，再放原有石片。落葉與光地皆使用固定配置，每次進場畫面一致。
- `creek.ts` 讓左右溪岸各自隨地形起伏，使用蒙版柔化貼圖外緣並保留溪心紋理。沿岸用既有岩石和灌木打散接縫。水紋沿溪道往下游淡出，兩處飛瀑沿用橋圖內的既有瀑面，再加少量流線。未來可在瀑布配置加入獨立瀑面素材。
- `vegetation.ts` 管理遠景、前後遮擋物和低層薄霧。少量過濾日光從現有空地落入，可用原有環境光設定關閉。減少動態時停用環境動畫，保留靜態光影。
- 古鳥居、木橋、藏寶路與風靈神龕的場景座標、顯示層和互動仍可分別配置。神龕目前沿用靈霧和提示。後續美術可用相同座標與原點替換，再依需求增加獨立遮擋層。

## 待製作的正式素材

| 優先 | 需要的素材 | 交付要點 |
|---|---|---|
| 1 | 溪水、左右濕岸、岸石、轉彎與瀑布組 | 可銜接平鋪的水面，獨立柔邊與短瀑面。保留水流方向、岸腳和橋頭接縫參考。 |
| 2 | 竹梢、竹根及灌木變體 | 按腳點與樹冠分層的透明部件，至少具疏、中、密三種剪影。提供遠景冷色變體，留出主路和地標視線。 |
| 3 | 濕苔、落葉、踏石與溪邊泥地 | 提供可無縫平鋪底圖、局部貼花和過渡邊。暗處維持可辨路徑。 |
| 4 | 橋欄、古鳥居與風靈神龕 | 石座、橋面與前欄分層。交付柱腳、原點與前景遮擋參考，保留隱路和神龕入口的視線。 |

新版未加入外部美術。瀑面和橋欄仍耦合在原橋圖，岸水材質近看可見重複，較古老的 Safari 若忽略 Canvas 2D `filter`，岸邊會較硬。視覺岸線允許少量裝飾性偏移，實際碰撞沿用既有河道。

## 行動成本與快取建議

Chromium 目錄列舉實測了紋理的像素尺寸，以下以 RGBA `長 × 寬 × 4` 估算，並非測得的瀏覽器程序或 GPU 記憶體。

| 項目 | 估算 |
|---|---:|
| 場景及基本角色，未計按需圖集與 256 px 預覽衍生 | 10.96 MiB |
| 瀏覽器經溪岸、木橋及探索點的測試場景，含東向跑步和待機圖集 | 16.96 MiB |
| 新地表 610×445、溪床 360×668、日光圖 128×128 合計 | 2.02 MiB |
| 原本溪床 433×890，相較本次三張環境圖 | 1.47 MiB，差額約增加 0.55 MiB |
| 場景建立時的短期溪水畫布 | 額外約 0.92 MiB，合成後可回收 |

落葉、光斑和河岸只在場景建立時合成。觸控環境最多有 13 個溪水／瀑布流線，減少動態時無環境 tween。區域放大後，畫布與影像來源會各自占用記憶體。實機峰值、iOS 柵格化成本、DPR、合成緩衝區與 GPU 副本仍待測。四向動畫分支已有新增 atlas 全載約 84.5 MiB 的估算，合併後須加上既有場景和其他動畫。

建議後續以 **256 px 預設、384 px 主動選取**，為行動版動畫先試行約 **16 MiB** 的 RGBA 預算。追蹤每張圖集的尺寸與最後使用時間，保留正在顯示、即將切換和載入中的圖集。其餘超出預算時依最久未用順序釋放，等精靈切到新圖集或站姿後再移除老紋理及相關播放格。請求失敗保留站姿，重試採明確操作或退避。離開預覽時清理場景所有權的紋理、計時器與下載，避免和其它頁面共用的素材被清掉。此為下一階段方案，本次保留既有動畫快取。

## 整合

與四向動畫分支唯一共同修改的檔案是 `forest-preview/ForestScene.ts`。環境接點在匯入、建立圖層與地標方法。動畫分支在狀態選取和畫面更新，合併時保留兩邊接點，再複測同一地點的過橋、移動和停格。本分支可獨立於四向動畫部署。Chapter 1、英文學習、存檔及 PWA 未改。
