# 影空 2.0 霧竹林構圖工作台

從美術工作台選「霧竹林角色構圖」，或開啟 [GitHub Pages 預覽](https://hotblakt.github.io/three-realms-english-quest/forest-preview/)（合併部署後顯示新版）。本機可執行 `npm ci`、`npm run dev`，再開啟 Vite 的 `/forest-preview/`。右上「構圖設定」可即時切換角色、角色高度、貼圖解析度、鏡頭、平滑跟隨、陰影、環境光與視窗模式。沉浸滿版使用安全區內的可用視窗，保留瀏覽器本身的介面。

## 素材稽核

從私有素材庫的固定提交取回 ZIP。以唯一成員名稱、允許的頂層路徑、檔案上限、PNG 格式、尺寸上限、ZIP CRC 和完整解碼驗證 13 張稿件。每張稿件都含 alpha 通道，其中構圖稿的 alpha 沒有全透明像素。[逐張尺寸、alpha 數量、雜湊與缺陷](eiku-composition-provenance.json)

`eiku-hero-reference-v001.png` 是英雄造型概念，正交的 `eiku-front-reference-v001.png` 用來對照臉、深藍圍巾、琥珀眼與青黑服裝。`eiku-gameplay-reference-v001.png` 指引林間景深、石路留白、木橋及暖燈的位置，場景使用既有霧竹林的分層實景。四張正交參考稿保有同一套站姿基準，適合做南、北、西、東對位。斜向稿在刀身、刀鞘、姿勢與風效上有明顯出入，保留在私有庫。

四向衍生稿以等比例縮放，站高 316 px，腳底原點 (192, 338)，輸出至 384×384 透明 WebP。清掉低值 alpha 浮點與可見投影，重繪正面與側面護額為兩道原創風紋。腰包、刀柄、圍巾方向與部分服裝飾紋仍需人工統一；站姿鏡頭較平，方向切換仍會看出剪影落差。四張稿均為構圖候選，走動、揮劍與閃避時維持對應方向的站姿。

## 構圖比較

- [現用影空，100%／1.0 倍](../art/preview/eiku-composition/original.webp)
- [影空 2.0，160%／1.15 倍](../art/preview/eiku-composition/candidate.webp)
- [木橋西側至東側的橋面構圖](../art/preview/eiku-composition/bridge.webp)
- [模擬 iPhone 橫向觸控](../art/preview/eiku-composition/iphone.webp)

建議先用 **160% 高度、256 px 貼圖、1.15 倍鏡頭和沉浸滿版**。在南入口與橋上，圍巾、佩刀和站姿容易辨認，岔路及溪岸也留在視野內。100% 時眼睛與護額在林地紋理中難讀；180% 或 1.45 倍可看服裝細節，但高倍率下可見的路口與景物較少。256 px 貼圖已高於這組預設的畫面投影尺寸。192／256 px 從四張 384 px 主紋理按需建立，尺寸切換時角色的腳底、站高與碰撞體皆固定。

新增圖片下載量約 200 KiB。若四向的三種尺寸都載入，RGBA 紋理約 3.8 MiB，另計瀏覽器與 GPU 的副本。滿版高倍率、首次生成貼圖、半透明竹冠與環境光仍需用實機量測。現有溪床和橋圖的接縫可見，橋欄與橋面仍為同一圖層。此原型只用記憶體設定，正式遊戲的存檔、英文學習與 PWA 繼續使用既有路徑。
