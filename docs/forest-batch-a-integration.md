# 霧竹林 2.0｜溪流與瀑布批次 A

整合範圍是工作台內的霧竹林預覽。溪流沿用原有河道遮罩、溪岸碰撞與木橋通道。新素材只影響環境繪製，不參與導航或碰撞。瀑布面、岸礁、陰影、溪水與泡沫分別設定深度，竹林的前景遮擋仍由現有系統處理。

## 來源與取捨

從私有素材庫的 `assets/forest-v2-batch-a` 固定提交 `67cde5beb89d2cf5888e8f8484445cd1dee91397` 讀取 `incoming/forest-v2-batch-a-candidates.zip`。核對 17,560,997 bytes、ZIP CRC、12 個安全且唯一的項目，以及內部清單列出的六張原稿與三張 WebP 的雜湊、像素尺寸和色彩模式。各張原稿與衍生圖的核對結果收錄在 [來源清單](forest-batch-a-provenance.json)。

| 項目 | 判定 | 驗收觀察 |
| --- | --- | --- |
| 溪水原稿與平鋪衍生圖 | 採用平鋪衍生圖 | 原稿的半透明度遍及全幅，對邊有明顯色差。衍生圖的相對邊像素在兩軸完全一致，降低飽和度後與林中陰影更一致。3×3 仍看得到亮紋重複，場景用旋轉、縮放與窄河道遮罩減輕規律感。 |

處理配方與驗收方式：

- 水面使用交付的 512 × 256 無縫 WebP，色彩強度乘 0.79，再以 `#143b36` 混入 23%。輸出無損 WebP。以兩軸首尾像素逐一比對，並檢查 [執行圖磚的 3×3 平鋪](../art/preview/forest-batch-a/water-3x3.webp)。原始對邊 MAE 為 13.608／8.874，交付無縫圖與整合後成品皆為 0／0。
- 三件透明物件先按來源清單的裁切範圍取材，僅清除 alpha ≤5 的殘點，依透明輪廓裁邊，再以 Lanczos 等比例縮放並輸出無損 WebP。保留霧化水邊、岩縫和抗鋸齒。
- 執行時沿用有機河床遮罩，以羽化河岸接到濕岸與礁石。上游放入獨立瀑布物件，沿用橋旁小落水。額外水流、薄泡沫、飛沫與接地陰影由場景繪製，與原畫的合成泡沫分開。系統偏好減少動態時保留靜態水紋，停用動畫。

批次 A 低於 2.00 MiB 預算。沿用既有場景的 48.96 MiB 紋理估算基準（256 px 四向 Run／Idle、背景 Cast 與一張衍生站姿），加入本批後約 **50.14 MiB**。這是以紋理尺寸乘四的估算，不含暫時性 Canvas、畫布／GPU 緩衝、驅動配置及另外手動載入的動畫解析度。溪流重用既有河床畫布與流線紋理，未引入動畫圖集驅逐。實機 Safari 的初次解碼、長時間遊玩效能與記憶體峰值仍待測量。
