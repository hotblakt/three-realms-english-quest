# 開發與發布指標

每次以 PR SHA、素材版本或部署 SHA 為記錄鍵。保留工作類型、計量起訖點、樣本數與來源。CI、GitHub 部署及碼表紀錄標為「實測」，推算值標為「估計」並列出假設。缺資料填「未量測」。跨批次比較使用相近任務與相同驗收尺度。

| 指標 | 定義與計算 |
|---|---|
| 品質 | 以原定驗收條件的通過數／總數、發布後回歸數及實機案例結果表示 |
| 生產力提升 | 同範圍同品質基準下，用基準人工分鐘減本期人工分鐘，再除以基準人工分鐘 |
| 自動化率 | 可驗證由工具獨立完成的步驟數／事先定義的適用步驟數 |
| 人工介入時間 | 人員實際操作、審閱與排障的分鐘總和，等待時間另記 |
| 一次通過率 | 首次送審即核准的件數／送審總件數 |
| 週期時間 | 從工作進入執行到依定義驗收或部署完成的實際經過時間 |
| 每件核准素材成本 | 批次的可歸屬費用（含失敗重試）／核准件數，人工成本如採計須另列，核准數為 0 時不計比率 |
| 重工率 | 需要修正再送審的件數／送審總件數，另記重工時間與次數 |
