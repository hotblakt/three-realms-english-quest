# 三界世界設計

區域連接、探索、戰鬥、靈伴與回程是長期骨架。第一章仍在隱竹村及竹林試煉成立。12 月 22 日展示應先呈現村莊、守衛戰及風刃，再以少量霧竹林資產展示延伸方向。這份文件的未來區域都是設計目標。

## 區域資料契約草案

首個第二區切片到位後，新增小型 TypeScript registry。先登錄現有村莊及試煉作為相容項目，僅將新入口移交給共用轉場函式。未實作區域留在上表，直到有畫面和可走路線才登錄。既有戰鬥、任務、輸入、語音、Phaser Arcade、深度和相機沿用。

| 欄位 | 資料／規則 |
| --- | --- |
| `id, realmId, nameZhTW` | 固定識別與繁中顯示名。存檔使用固定 ID，改中文名稱不需移轉。 |
| `size, cameraBounds` | 每區自己定義正整數寬高與鏡頭範圍。入口/座標均以本區世界單位。 |
| `spawns` | 命名落點，例如 `from-village`，指定 `x, y, facing`。如指定 ID 無效，使用安全預設落點。 |
| `exits` | 互動矩形、目的區 ID 與落點 ID、條件 ID。村莊與霧竹林可往返，明確留出角色碰撞體寬度。 |
| `unlock` | 少量窮舉條件，例如章節完成、收藏取得或區域旗標，判定沿用既有章節狀態。 |
| `collision, navigation` | 沿用靜態矩形與圓形 Arcade body。路徑初期用巡邏起訖與安全落點驗收，真的有敵人需要繞障礙時才加入路點網路。視覺竹冠不寫成阻擋。 |
| `layers` | 遠景、地面、地影、依根／牆基 y 排序的道具、前景、霧、HUD。註明貼圖鍵與遮擋策略，互動資料獨立。 |
| `npcs, encounters, quests` | 穩定放置 ID、座標、資源鍵和任務或遭遇 ID；由既有場景回呼及戰鬥載入。 |
| `collectibles, chests` | 穩定與區域唯一的物件 ID、位置、取得條件及獎勵 ID。發獎與取得旗標同次更新，以讀檔避免重複領取。 |
| `waypoints` | 預留可解鎖地標與安全落點。首切片以步行轉場，快傳後續再接。 |

轉場先驗證條件與目的落點，取得目的資源後才停止目前互動並切場。載入失敗保留目前位置、輸入及回程路徑。切場沿用現有 pause／離場麥克風清理，不把語音資料帶到目的區。以 registry 找有效座標與鏡頭界限，成功後更新最後安全落點。離場釋放物件及無引用貼圖，共用圖集保留。

區域進度另存版本化 `three-realms:world:v1`，草案含 `lastSafe: {regionId, spawnId}` 與按區索引的 `visited, questFlags, clearedEncounters, collectedIds, unlockedWaypoints`。既有章節 v2、舊訓練 v1 和英文 EXP 鍵照舊。沒有世界記錄時仍由現有章節選村莊或試煉。未知區域、落點失效或資料損毀時，保留可讀的章節與學習記錄並回原安全檢查點。先測舊存檔重載、雙向往返、重複拾取和目的區載入失敗，再考慮其他區域。

## 下一區：霧竹林

建議工作尺寸 1120 × 720。村莊東側主路的接點候選 `(804,270)`，實裝前依碰撞及讀圖調整，保留西側既有竹林試煉入口。最小切片可在第一章完成後開放，敗退時可回村。

```text
                            北
                  [靈伴伏筆・古竹壇]
                           │
             [稜線路・小戰鬥 B] ── [竹後支口→隱藏寶箱]
                    ╲     │
村莊東口 ⇄ [安全入口] ── [風紋岔口] ── [林地・小戰鬥 A]
                    ╲                    ╱
                     └──── [南側回程捷徑] ┘
                            南
```

- **落點**：`from-village` 約 (92,500)，旁邊留可隨時互動的回村出口；主岔口約 (410,390)。戰鬥 A 在東林地 (800,380)，B 在北側稜線 (520,200)。主路淨寬約 96 世界單位起，竹冠可局部遮腳但標記與警示維持清楚。
- **探索**：隱藏寶箱靠北東竹後，入口用缺一叢竹和微暖反光提示。開過的箱維持開啟。古竹壇在北側提供未來靈伴相遇，先留一個可讀的環境地標。南側捷徑回起點，不以打完所有敵人作回村條件。
- **資產首批**：前景竹叢 A、疏竹 B、至少一種遠竹合層、林地／石路過渡、可拷貝的薄霧遮罩、村口門標、少量苔岩與暖燈。
- **完整切片再補**：北側古竹壇、寶箱開關、可沿用的風靈、靈伴剪影、路口標記、可選的橋面／欄件。先通過[首件審批與尺寸測試](asset-production-guide.md)，再配置碰撞和轉場。

本里程碑交付資料契約、路線與規格，沒有新增遊戲入口、區域存檔鍵或空白地圖。
