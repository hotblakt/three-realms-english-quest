以 PR #35 合入的 `350d0f139ccc0068a6153afa261f9265dc9e9e4b` 為基準。製作人對 **PR #35 候選入口的 Safari 實機驗收為 7／7 通過**，涵蓋啟動、生態與根部及地面貼花、遮擋、四向移動及收步、溪流瀑布與過橋，以及 3–5 分鐘流暢遊玩。正式入口的實機驗收仍待進行，原始卡死根因未確認。

## 候選與正式等同性

- `/forest-preview/` 和 `/forest-batch-b-preview/` 指向同一個 PR #35 啟動模組。Vite 把同一份內嵌啟動程式放入兩個入口，保留入口模組前的稽核與看門狗。兩者只有入口標題和返回連結不同。
- 把 PR #34 的場景介面提取成共同 HTML 範本。PR #35 原本在讀入該 HTML 後移除入口 Script，此次在共用範本直接省去同一行。場景 DOM、角色、環境及遊戲邏輯沿用原路徑。獨立 `/forest-diagnostics/` 使用同一份介面範本，維持 A–E 職責。
- 沿用動態模組初始化、選用圖集獨立下載、SHA-256、顯式解碼、手動紋理註冊及首次繪製確認。保留選用資產五秒逾時、必要啟動二十秒看門狗、舊竹林備援、必要 Run／Idle 四方向就緒門檻及不操作存檔的重新載入。
- 正式建置比對兩頁的入口 JavaScript、CSS 與 HTML 內嵌看門狗相同。內嵌看門狗與 PR #35 逐位元組一致。依 SHA-256 核對 55 個 `public` 檔案在 PR #35、此次來源及 `dist` 全部相同。Batch B 原圖集 SHA-256 為 `8b11aaad52d4f52daffa69bed77f7b589f74a61eacc9b0df6daacc0810c9405e`，Batch A、角色動畫與其他素材均無來源變更。

## 驗證紀錄

- `npm ci`、正式建置、51 項 Node 與 7 項 Python 回歸測試通過。
- 兩個入口均在正式 GitHub Pages 子路徑通過 Chromium 模擬 iPhone／iPad 橫向冷啟動和各三次同工作階段重訪，Auto、強制 Canvas 與強制 WebGL 均能繪製 Batch B。
- 兩個入口對選用圖集 404、停滯、解碼拒絕、WebGL 提交失敗均使用原竹林。必要北向 Run 404 顯示資產並保持鎖定，解除故障後可重試，本機儲存標記仍在。必要請求停滯於二十秒提示重試，並顯示未回應項目。
- 正常入口通過 Chromium 四向 Run／Idle、北向收步足點、竹冠深度與淡化、溪岸碰撞、過橋、寶箱、神龕、捷徑、減少動態及 iPhone／iPad 橫向觸控測試。正式建置通過工作台往返、第一章進村和獨立診斷 A–E。診斷的混版圖集和必要資產 404 仍顯示錯誤。
- 這些驗證使用 Chromium，正式入口在 Safari／主畫面模式的實機證據尚待製作人提供。PR #35 實機結果適用於候選入口。
