# 霧竹林地標與風靈 1.0｜Batch C 候選版

遊戲基準為 PR #36 的 `afb60145c4cda66db8e1a82e2e34216a7993649b`。本次額外入口為 `/forest-batch-c-preview/`。正式霧竹林、Batch B 候選和 A–E 診斷不載入 Batch C。溪流、碰撞、橋口、地圖範圍、神龕互動、角色比例及存檔沿用基準。

## 來源與逐件驗收

從私有素材分支 `assets/forest-v2-batch-c` 唯讀取得固定提交 `471479f70e2d8e67d3a9a7d184ad2c71c5eda3e3`。ZIP 路徑為 `incoming/forest-v2-batch-c-candidates.zip`，實測 8,154,989 bytes，SHA-256 為 `efe6af5c53a2afe34fccb5d4b52c8e06e8024188d2ab226b1cc407feecd6cb20`。19 個項目通過安全路徑、重名、ZIP CRC 檢查。內部 `SHA256SUMS` 覆蓋並核對其餘 18 個項目。兩個原稿均為 1536 × 1024 RGBA，12 個獨立模組均為 RGBA 且具有實際透明邊緣。交付用 1024 × 480 圖集的 12 個幀不重疊、未超出四像素邊距，幀 alpha 範圍符合圖集 JSON。原稿與交付預覽保留在私有庫。[逐檔來源、尺寸、alpha 與雜湊](forest-batch-c-provenance.json)

逐件以深綠和淺米色底檢查輪廓，再比對森林的斜俯視、左上光與角色足點。判定的「採用」允許等比例縮放與場景色調校正。

## 配置與限制

- 用 318 px 寬的橋面試疊同寬與獨立寬度欄杆，保持比例並分別調整遠近欄。兩種試疊仍有柱腳懸空、拱線不一致或欄端落在橋翼之外。移除舊合成橋也會移除溪瀑局部。候選版因此保留 PR #36 橋圖、橋底繪製順序及原通行帶。分層橋未上線。後續需要同一視角、同一原點的橋面／近欄／遠欄輸出及獨立溪瀑。
- 神龕合成圖在 `(920,117)` 依階梯底緣接地，陰影用既有柔影紋理。原風靈互動及圖示仍依 `(920,123)` 判定。燈座足點為 `(564,483)`、`(778,463)`、`(856,191)`、`(966,130)`，沿路肩配置。新增景物未加碰撞。
- 圓環、弧線及旋風在地面層，蝴蝶在神龕附近。四個固定效果物件共用圖集，兩個低速 Tween 控制透明度與蝴蝶微移。減少動態保留靜態提示，關閉新增 Tween。暖光及風效遵循既有光線診斷選項。

## 圖集與載入

使用 `python scripts/prepare-forest-batch-c.py <固定 ZIP> public/forest-batch-c/forest-landmarks.webp docs/forest-batch-c-provenance.json` 重建。八件依固定順序等比縮放。四件效果只在外緣做柔化，保留直通 alpha，輸出無損 WebP。各幀有 4 px 延展及額外 4 px 透明間距。兩次執行的圖集與 JSON 逐位元組一致。

| 項目 | 結果 |
| --- | --- |
| 尺寸 | 640 × 336 |
| 壓縮傳輸 | 191,210 bytes |
| 解碼 RGBA | 860,160 bytes（0.8203 MiB） |
| Batch C 預算 | 2.50 MiB |
| 預設 256 px 全場景紋理 | 約 52.09 MiB（51.27 + 0.82） |

估算不含 Canvas、GPU 暫存及切換高解析角色後的快取。燈光與接地陰影重用現有紋理。

候選入口共用 PR #36 的動態初始化、必要四向 Run／Idle 檢查、二十秒看門狗、首次繪製與重試。只有 Batch C 入口注入獨立、最多五秒的地標準備。地標並行下載，核對大小與 SHA-256、解碼後手動註冊。故障時沿用原地標，Batch B 照常啟用。重試無存檔操作。其他入口不請求此圖集。

## 回歸結果

- `npm ci`、正式建置、52 項 Node 及 9 項 Python 測試通過。新增測試涵蓋 Batch B／C 選用逾時隔離、來源驗證拒絕與執行圖集雜湊、透明留白及預算。
- Chromium 正式建置測試 iPhone／iPad 橫向各一次冷啟動與三次重訪，以及 Canvas、WebGL。選用 Batch C 404、停滯、解碼拒絕與紋理註冊錯誤皆退回原地標，Batch B 保持啟用。必要北向 Run 404／停滯保持控制鎖定，恢復請求可重試，本機儲存標記維持。
- Chromium 驗證四向 Run／Idle 與北向收步足點，竹冠淡化與深度，原橋面低於角色、過橋通道、溪岸碰撞，神龕、寶箱、返回捷徑，減少動態及 iPhone／iPad 橫向觸控。正式入口及 Batch B 候選皆成功並無 Batch C 請求，診斷 A–E、工作台往返及第一章進村通過。
- 尚未進行 iPhone／iPad Safari 或主畫面 PWA 實機測試。實機驗收仍需確認圖集冷解碼與長時間效能，以及神龕在不同相機構圖下的輪廓可讀性。
