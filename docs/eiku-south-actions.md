# 影空 2.0 南向動畫驗收

從既有美術工作台開啟「霧竹林角色構圖」。預設「FrameSprite 自動方向」保留向右的既有跑步，向南移動時使用九格新跑步，停下後回南向站姿。構圖維持 207% 與 1.3 倍鏡頭。選「FrameSprite 南向跑步檢閱」可原地試播、暫停、逐格與切換 256／384 px。[預覽（合併部署後更新）](https://hotblakt.github.io/three-realms-english-quest/forest-preview/)

## 來源

唯讀取得私有庫 `main` 的 `incoming/eiku-front-reference-v001-Run_60_sheet.zip`，提交 `dca9116f79ac29571a5dce826c93493f5dc6a38f`。ZIP CRC 通過。依 `layout.json` 的列優先座標及起始索引解碼全部 60 張 768×1152 RGBA 格。四頁各含 18、18、18、6 格。採樣時間單調遞增，延遲合計 4,458.333 ms，平均 13.458 FPS。匯出檔記錄素材格位與時間；生成品質、Enhance 與同首尾設定依上傳者提供。[ZIP、分頁、時間與區段來源紀錄](eiku-south-actions-provenance.json) · [60 格聯絡表](../art/preview/eiku-south-actions/contact.webp)

## 動作判定

所有來源索引從 0 開始。自動檢測把 0–4 標成前段站姿，5–53 標成移動（含加速與減速），54–59 標成後段站姿。這是動作範圍的初篩，循環端點需逐格選定。

- **南向跑步通過霧竹林預覽驗收。** 採索引 17–25，9 格，合計 667 ms，建議等速 13.49 FPS。兩次跨步、落腳與換腳可辨，下一循環的 26 接近 17，因此排除重複邊界格。共用腳底原點與等比縮放保留上下起伏，低透明噪點和偏綠邊緣保守清理。髮型、藍圍巾和腰間刀鞘維持辨識度。圍巾尾與衣角在接縫略有跳動，跑姿回站姿仍可看出剪影變化。
- **南向待機暫不採用。** 優先檢閱 57–59，兩腳位置與站姿穩定，但主要是圍巾收勢及近重複格。前段也沒有完整可辨的吸氣、吐氣與回位。靴下有少量偏綠殘影。沒有合格循環或建議 FPS，保留既有站姿，未輸出待機圖集。

兩張合計 7.31 MiB，另計 GPU 副本。它們只由霧竹林載入。建議一般預覽使用 256 px。

## 新動作匯入

在遊戲庫執行 `python -B scripts/import-framesprite-actions.py 源ZIP 配方.json 輸出目錄`，離線工具使用 Pillow 與 NumPy。通用讀取器驗證檔名、CRC、PNG、alpha、分頁順序與時間。偵測器比較下半身剪影與首格站姿，可用配方調整閾值，適用於站姿開場、同一機位的素材。每個動作可用 `range: [start,endExclusive]` 覆寫範圍，設定 `approved: true` 後才會輸出圖集。若首格在跑動、角色長時間被遮住或上下半身比例特殊，應用聯絡表改用手動範圍。工具產出聯絡表、逐格分數、圖集清單與來源資訊。

合併生成適合先試出角色的動作轉場，這批只能核准跑步。批次正式素材建議為待機和跑步各輸出獨立完整循環，保留明確的首尾與共同腳底線，再對照角色比例、接地與刀鞘位置。
