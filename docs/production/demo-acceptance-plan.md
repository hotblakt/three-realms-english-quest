## 必要體驗與驗收案例

目標是讓國小玩家從新存檔完成約 10–15 分鐘的冒險，讓無程式背景的成人觀眾看懂目標、選路、結交靈伴與取得能力。主線為村莊線索 → 主徑或瀑布側徑 → 疾風棲地與短句交流 → 守護者 → 風刃與成長回饋 → 捷徑返程及結束提示。以首次可控制開始至結束提示計時，包含探索、對話、迷路與遊戲內重試；載入及場外中斷獨立記錄。

| ID／驗收項目 | 可重跑的通過條件 |

| V01 日系動畫 2.5D | 以核准的角色與場景參考，在村莊入口、主徑、瀑布、棲地、守護者場地、回程各存一張遊戲比例畫面。必要畫面無暫用診斷圖、缺圖、錯幀、可見接縫或透明邊污染；角色、敵人、互動地標、通行帶可辨。每個展示素材有原創或授權來源。 |

| U01 HUD | 生命、當前目標、可用互動、技能變更及獎勵在對應狀態可見，生命與檢查點一致。兩種裝置安全區內無重疊、截字、診斷資料或必要提示被對話蓋住；可由目標指引從村莊出發並辨識結束。 |
| U02 音樂和音效 | 有一段授權探索音樂或氛圍，互動、命中、預警與獎勵各有明確回饋。首次手勢後可正常播放，靜音即生效，背景往返不疊播、退出練習不殘留收音，靜音時仍有預警與獎勵的視覺訊號。 |
| D01 觸控 | 每個 iPhone／iPad 模式中驗證兩個橫向方向各一次，搖桿＋揮擊、搖桿＋閃避、互動與對話捲動各 5 次。結束觸點、旋轉、背景與失焦均釋放輸入，操作無卡鍵或非預期頁面捲動。直向有提示並暫停，轉回可繼續且不自動恢復錄音。 |
| D02 Safari／PWA | 安裝圖示、名稱、子路徑與主畫面啟動模式正確。每格矩陣完成新裝、使用同一入口重訪、背景恢復、由上一版更新及弱網恢復，無黑屏、意外重載或快取新舊資源混用。斷線時若必要資源不可用，有可見訊息及重新連線後的重試路徑。 |
| D03 啟動與載入 | 從開啟 URL／圖示計時，1 秒內顯示載入或入口畫面，冷啟動至角色可控每次 ≤12 秒、暖啟動每次 ≤5 秒（下節固定網路條件）。測試必要資源缺檔／停滯時維持鎖定、20 秒內可見重試；選用資源五秒時限及備援分別注入故障；解除故障後無須清存檔即可重試。 |

| D05 效能與記憶體 | 相同實機各跑一次 15 分鐘高負載路線及三趟相同的場景往返。可操作階段 p95 幀時間 ≤33.3 ms，無超過 250 ms 的畫面停頓，無系統終止與非預期重載。記錄可用的記憶體峰值與每趟回同場景靜置 30 秒後的數值，第三趟 ≤第一趟的 110%；另比較資源快取／計算的解碼紋理體積與 PR #39。 |
| D06 無障礙與減少動態 | 重要文字對比 ≥4.5:1，必要圖示及控制邊界 ≥3:1，觸控目標至少 44×44 CSS px。VoiceOver 可讀 DOM 選單、按鈕、狀態與返回，鍵盤可進出選單且焦點清楚；文字或形狀與色彩／音效共同提示。開啟系統減少動態後檢查晃動、閃光及背景飄動減弱或停用，預警、操作和進度仍完整。 |
| R01 重玩 | 兩份新存檔各跑不同路線，再以已完成存檔重訪兩路。可回收漏掉的側徑發現，已領寶箱與一次性獎勵無重複。第二趟可指出不同地標、事件順序或回報，兩條路皆可收尾。 |

**製作人主觀驗收。** 實際觀看遊戲比例畫面並操作全程，分別簽核角色和世界的日系動畫風格是否一致、疾風是否令人想帶走、戰鬥是否清楚且公平、英文是否像自然對話、音景與節奏是否支撐成人觀眾理解，以及第二條路是否值得再玩。每項記錄接受／退回及影片時間點。獨立 QA 同時保留客觀 ID 結果。

**可選延伸。** 額外環境敘事、疾風互動變化、較精細音景或另一個可選收藏品。必要門檻未齊時先延後延伸；任何納入候選的延伸均須通過啟動、效能、存檔與核心流程回歸。本展示的範圍為一隻靈伴、一場守護者與一個短英語交流。

## 證據與缺陷分級

- **阻擋發布**：任一必要門檻失敗或缺證、無法進入或通關、迷路無回程、拒絕麥克風會卡關、觸控失靈、重試無效、黑屏或重載、存檔損毀或重複給獎、看不見必要提示或預警、超出效能門檻、缺少素材授權、CI 失敗或候選 SHA 與證據不符。無可複驗的安全回退同樣阻擋。修正後重跑失敗案例與關聯回歸。
- **非阻擋**：只有在所有必要門檻仍達標時，可列入次要局部穿插、可讀的非必要文案錯字、未納入的延伸項等。QA 記錄影響、重現方式、負責人及處置，製作人書面接受剩餘影響。
- **取證**：每項標記通過、失敗、未測或受阻，附 SHA、入口、裝置／OS／模式、帳號或存檔類型、網路、輸入步驟、預期與實際、計時／日誌／畫面。QA 記錄缺陷與重測關係，製作人簽核風格及放行。候選 SHA 更新後重跑自動化及實機煙測；按改動重跑受影響驗收，跨系統改動重跑完整路徑與回退。

## 自動化、獨立畫面審查與實機

1. **既有 CI**：候選提交須通過 PR Quality 與彙整的 PR quality gate。Node.js 24 執行 `npm ci`、`npm run build`、`node --test tests/*.test.mjs`；Python 3.12 安裝 `tests/requirements.txt` 後執行 `python -B -m unittest discover -s tests -p 'test_*.py'`。保護第一章、學習、動畫資料和舊存檔。
2. **整合新增測例需求**：以固定種子／時鐘及存檔樣本驗證兩路可達性、碰撞與遮擋、疾風狀態、拒權和輔助、命中與閃避邊界、重試及獎勵冪等、舊檔遷移和交易中斷。瀏覽器煙測從正式 Pages 子路徑入口執行，覆蓋首頁、進村至返程、重訪、直橫轉換、PWA manifest、必要／選用資源故障注入與恢復。保留 Canvas／WebGL 正式入口 Run／Idle 檢查及固定鏡位對照。語音替身只驗證事件分支；實機收音、手感及畫質以人工證據驗收。
3. **獨立畫面審查**：由未製作該場景或素材的人審 V01–V03 與 HUD，使用兩種實機尺寸的原比例畫面，與核准參考及 PR #39 固定鏡位比較。另附四向跑停、橋與神龕進出、疾風相遇、守護者預警、減少動態的短片。記錄鏡位、方向、幀號、遮擋、足點和顏色問題；製作人另簽風格感受。
4. **實機矩陣**：至少一支 iPhone 與一部 iPad，各測 Safari 分頁及主畫面 PWA，共四格。製作人事先確認機型、支援 OS 與最弱支援裝置，公布機型、OS、方向、畫面尺寸及展示入口。在每格以相同 HTTPS／Pages 子路徑候選、穩定展示網路各測 3 次冷啟動和 3 次暖啟動。冷測用隔離新資料與冷快取，暖測關閉後用同一資料重訪。記錄網路基準，另測弱網、斷線及恢復。每格至少完整一趟，四格合計覆蓋兩路與所有異常案例；每格皆測雙指、旋轉、切背景、麥克風允許／拒絕、PWA 更新或 Safari 重訪及保存。iPhone 檢查瀏海／底部手勢，iPad 檢查工具列與可用視窗範圍。模擬與實機分開登錄。
5. **量測**：冷暖啟動用錄影／時間戳，幀時間與記憶體用適用的 Safari 工具或候選診斷，保存原始資料、取樣方式和執行是否連接偵錯器。以相同網路、裝置、路線、狀態比較 PR #39 和候選。記憶體工具受限時記錄可觀察的快取、紋理解碼估算、系統終止與重載，請製作人在驗收前確認代理指標或安排可取證工具；D05 在取證方案與結果齊全前維持受阻。

## 兒童試玩與成人彩排

經監護人同意及兒童同意後，邀請至少 5 名國小玩家，涵蓋低、高年級及不同英語程度。用新存檔和兩種尺寸，主持人先給同一開場說明，之後觀察並只在玩家求助時記錄提示或介入。記錄分段時間、迷路點、重試、語音備援、放棄及回程，以匿名代碼記錄，錄音或畫面依同意範圍處理。門檻為至少 4／5 在 10–15 分鐘內無操作代打、無指路提示通關，至少 4／5 能用自己的話說出目前目標、辨出一項預警並採取閃避、說明疾風加入及風刃用途。以交替起始路線測試，至少 3／5 願意選另一條路且說得出具體理由。任何卡死立即記錄，兩名以上在同節點迷路超過 60 秒或需要同一提示，修正後以新玩家重測。

- [ ] 鎖定候選 SHA、候選 URL、展示 iPhone／iPad 與 OS、連線、音量、電源、新存檔與可回退版本。
- [ ] 確認自動化、獨立畫面、四格實機、兒童試玩證據及缺陷清單齊全，阻擋缺陷歸零，製作人簽核。
- [ ] 實際用展示裝置從冷啟動至結束彩排兩遍，分別走兩路。驗證可見開場、線索、疾風、英語、戰鬥、成長與回程；另走一次戰敗重試、拒絕麥克風與網路重試。
- [ ] 至少兩名無程式背景成人觀察完整一遍，兩人皆能在無技術解說下描述主角目標、疾風如何加入及守護者後得到的能力。
- [ ] 用獨立測試資料確認備用裝置與已核准備用版本能啟動。指定現場操作、說明、計時、故障切換及決策人員，記錄開始與完成時間。
- [ ] 核對實際展示入口對應已驗收 SHA，按發布協定另行取得授權；正式 URL 若有變更，再做實機煙測後才標記完成。

## 安全回退與待確認事項

候選有阻擋或正式入口回歸時，固定失敗 SHA、URL、階段、裝置與故障證據。發布前維持公開穩定版。活動中切換到已演練的備用裝置或已核准穩定入口，並說明展示範圍。已發布回歸時，以保護 PR 從目前主線反轉對應升版或切回已核准啟動入口，預設核對 PR #39，若需退到 Batch B，依正式入口升版文件及製作人授權處理。保留歷史、素材、診斷與玩家資料。用隔離副本驗證候選存檔向後相容；有不相容風險時，使用可保留原始資料的復原版或獨立展示資料，保留原始存檔直到驗證完成。復原候選須通過 CI、子路徑、Safari／PWA 冷啟動、重訪、核心路線及存檔煙測，獲授權後才發布並於正式 URL 複驗。[發布協定](../release-management.md) · [Forest 2.0 回退程序](../forest-v2-production-promotion.md)

待確認事項包括 A／B／C 的契約與固定 SHA、疾風身份及美術／聲音授權、實作與發布授權、最弱支援裝置、展示網路、效能及記憶體取證方法、參與者安排以及候選與備用入口。實機與人因結果、效能實測和回退演練均待候選版驗收。
