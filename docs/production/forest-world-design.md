# 霧竹林 3.0 世界設計

7A-5 工作流 A｜製作人審閱稿

以 Forest 2.0 為基準，展示範圍是一段可往返的森林冒險。兩路在東岸會合，疾風棲地與守護者區都能從任一路走到。玩家可在同次遊玩補探索另一側，無需重開存檔。

## 路線選擇

| 路線 | 動線與回報 | 環境敘事與引導 |
| --- | --- | --- |
| A 石燈主徑 | 南口 → 分岔 → 練習空地 → 木橋 → 東岸會合點。路短、回報直接，適合想練習閃避的玩家。規劃一組可重試的練習遭遇與一次性獎勵，獎勵種類由戰鬥工作流核定。 | 暖石燈在轉彎後仍可見。石板磨痕、一道淺刀痕和練習空地的破竹，暗示村民曾在橋外守路。進遭遇前留安全站位，橋面保持通行。 |
| B 瀑聲側徑 | 南口 → 分岔 → 既有西岔與寶箱區 → 隱藏瀑布觀景凹地 → 西岸上緣接回橋西。路較長，回報是發現瀑布、一次性探索寶藏及疾風線索。沒有額外必打遭遇。 | 當暖燈減少時，改以苔石、滴水與折竹朝同一方向指引。從寶箱岔路看得到凹口、轉過彎才看見瀑面。岩面有先民留下的風紋，潮濕足跡指向東岸，讓疾風的出現有前兆。環境聲輔助定位，靜音時沿石徑和足跡仍能找到。 |

B 的隱藏瀑布是草案中的**西岸探索支區**，位於不可涉水的觀景線外側。既有上游瀑布自木橋仍看得見。B 優先採用西岸折返或乾地環線，兩路共用唯一的既有跨溪橋口。若西岸環線的實際空間不足，B 可暫用觀景凹地原路返回分岔。回程標記、寶藏與線索都保留。

```text
南口 ⇄ 石路分岔 ── A 練習空地 ──┐
           ╰── B 西岔寶箱 ⇄ 瀑布凹地 ──┴── 橋西 ⇄ 木橋 ⇄ 東岸會合點
                                                               ├─⇄ 鳥居 ⇄ 神龕／疾風棲地
                                                               │                ╰─⇄ 守護者區
                                                               ╰─⇄ 東側捷徑 → 南口
```

疾風交流採短句與既有練習備援，麥克風拒絕不阻擋探索。風紋線索可提供交流提示，缺少線索仍可完成。守護者在棲地之外的獨立空地，從安全側就能看見預警。進入戰鬥、獎勵條件與復原由戰鬥工作流核定。離開守護者區可原路回東岸，使用捷徑回南口，或走木橋補西岔。

## 區域與出入口契約

只有 `misty-bamboo-forest` 為本設計的既有區域 ID。下表的分區 ID 是區內規劃鍵，無需各自開成獨立場景。出入口為命名錨點。數值標為「基準」時取自 Forest 2.0 的 `forest-preview/layout.ts`，僅供定位。其餘幾何須在整合前量測。

| 分區 ID | 進點 | 出點與返回 |
| --- | --- | --- |
| `misty-south` | `south-entry` 基準足點 (477,766)。未來村莊入口對應此安全錨點。 | `fork` 基準 (515,599)。南側保留 `village-return` 錨點，與村莊安全落點成對審核。 |
| `misty-lantern-trail` | `fork` 朝石燈主徑。 | `bridge-west` 基準西側通行點 (622,451)。練習空地外留原路回分岔。 |
| `misty-west-falls` | `fork` 朝西岔，`west-chest` 基準 (197,416)。 | `falls-lookout` 為待定新狹域。從 `west-bank-return` 沿乾地接回 `bridge-west`，備援為沿原西岔回 `fork`。 |
| `misty-bridge` | `bridge-west`；橋中心基準 (675,451)。 | `bridge-east` 基準東側通行點 (728,451)。固定雙向，橋口不作戰鬥封鎖。 |
| `misty-east-junction` | `bridge-east` 往東北，`east-junction` 基準 (850,285)。 | 沿鳥居到 `shrine-approach` 基準 (920,145)，或沿既有東岔到 `east-return` 基準 (1085,260)。返回互動落到 `south-entry`，維持既有回程方向。 |
| `misty-hayate-habitat` | `shrine-approach`，既有神龕互動基準 (920,123)。 | `guardian-entry` 是待定新通道。退路回 `east-junction`，疾風或英語流程不封鎖此路。 |
| `misty-guardian-clearing` | `guardian-entry` 由棲地外側進入，前方留安全檢查點。 | `guardian-retreat` 連回棲地與東岸。守護者失敗時回安全檢查點，離開後可使用原捷徑。 |

寶藏及遭遇使用獨立事件鍵。進出方向由區與落點鍵配對確認，避免傳送到水中或岩內。整合契約須確認舊存檔、重訪及一次性獎勵如何共用既有世界進度；此稿不指定新存檔格式。

## 通行帶與碰撞交接

- **世界設計**標出路徑中心、雙向可通行區、橋口、溪岸、懸崖、落點和安全檢查點。新增通行帶初稿預留約三個角色碰撞體寬度，遭遇外轉彎和返回口另留轉向空間。這是待試走的設計目標。橋口沿用既有通行幾何。
- **場景整合**由單一整合分支維護實際地形碰撞、步行區、出口觸發與場景布局。原溪岸阻擋與單一橋口保留。新凹地的觀景線以岩岸和地面明暗標界，避免可見足跡延伸到不可行走水面。竹冠可部分遮擋，危險邊與轉彎口仍要能定位。
- **美術**提供透明邊、落腳點及前後層。霧、落葉、風效、光圈和瀑霧僅作引導，與碰撞資料分開。硬阻擋只出現在可讀的根、石、溪岸或清楚界面。
- **戰鬥與靈伴**各自負責自身行為。戰鬥擁有命中、遭遇限制和獎勵，整合方核對退出與重試路徑。靈伴跟隨使用既有可走區資訊，互動提示不改變場景碰撞。
- **品檢**以新存檔各走 A 與 B，再由東岸捷徑回南口及雙向過橋。比對靜音可導航、色彩以外的路口提示、寶藏只領一次、守護者失敗可退回、拒絕麥克風仍能回程。模擬 iPhone／iPad 橫向後再做 Safari 實機走查，驗收至少確認入口、分岔、橋口、棲地和回程不需大段文字。

## 審閱決策與未解風險

本方案優先交付兩條回報不同的路、共用木橋與兩條可預期的回程。展示約 10–15 分鐘是規劃目標，兩路都在一次短流程內可辨，無需強制走完兩路。待製作人確認側徑是否以安靜探索為主、疾風線索的份量與守護者位置。待整合確認西岸連接的可用空間、守護者的安全退出位置及橫向手機的視線範圍。若場景或美術預算不足，縮短側徑，用既有石徑與竹冠形成瀑布凹地，維持其獨立探索回報。
