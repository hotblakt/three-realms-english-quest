## 疾風、戰鬥及資料契約

- **身份與招募。** `hayate` 是白色原創風靈狐，青藍靈紋、金鈴、藍圍巾。身份原稿未核准，依[素材計畫](forest-v3-asset-production-plan.md)先審主圖再授權四向與動畫。棲地採主動互動。確認短句配合過的練習或輔助即給等效故事進度。拒麥、辨識失敗、離線與退出均有文字、可重進及輔助。練習退出清理音訊，不存原音與逐字稿。
- **跟隨與羈絆。** 持久狀態為未遇見、已遇見、已加入羈絆 I、羈絆 II。跟隨沿合法玩家足跡，橋上單列，障礙時等待。超距或卡路只在離鏡且同區合法腳點復位，無安全點就等待或暫收起。遷移、失敗、回場用區域與安全錨點重建。探索提示只指未完成且可達的瀑布方向，可略過。守護者首次獎勵收據觸發羈絆 II 一次，先通關後招募時可補登。
- **遭遇配置。** `lantern-sprout`（竹芽），`east-wind-pair`（竹芽與風籽），`mosswood-guardian`（苔木守護者）。主徑練習可略過，側徑沒有必打遭遇。東岸房最多兩敵、共用一個攻擊名額。竹芽近扇形，風籽線形預警與投射，守護者扇掃／震波、核心露出可受傷。正式數值以 C 的設計表為首次調校起點。
- **狀態與時間。** 探索 → 安全入場 → 預警／活動命中／收招 → 結算待提交 → 已清除。另有暫停、失敗、退出。時間只計有效遊玩，以 ms 表示。劍擊前搖／活動／收招起點 60／90／150 ms，閃避沿用 310 單位／秒、160 ms 免傷、550 ms 冷卻。首次幾何重疊被閃避時給該敵 900 ms 反擊窗，使用後移除。失焦或轉直向凍結時鐘，回場重讀預警並清除殘留輸入。
- **資源與回復。** 生命起點 5 心、靈力上限 4、檢查點回到 5 心／至少 2 靈力。成功劍擊回 1，成功反擊額外回 1。風刃於成功釋放扣 2、取消前搖不扣，遇硬阻擋或第一敵即停止。射程由 144 至風紋強化 168 為調校起點。離場或戰敗清除該次敵人、投射、預警、待處理命中與疾風提示。安全點可重試或退出，反覆練習保留已得獎勵。
- **事件。** A 發布 `AreaReady/Exit{regionId,spawnId}`、`ArenaEntered/Exited{landmarkId,checkpointId}`，C 發給 `attemptId`。戰鬥事件共用 `encounterId,attemptId,seq,atMs`，附 `AttackTelegraphed/HitWindowOpened/AttackEnded{attackId,sourceId,shape,origin,facing,opensAt,closesAt}`、`HitResolved{attackId,targetId,result,hpDelta,spiritDelta}`、`CounterOffered{windowId,deadline,windBladeReady,safeAnchorId}`。B 供唯讀 `CompanionSnapshot{companionId,collected,bondStage,visualReady}`，只消費當次新序號、合規窗口。動畫、音效、HUD 只讀取，命中由 C 以嘗試／攻擊／目標去重。
- **落盤與冪等。** 整合器用版本化世界延伸欄位（下一個 Schema 版本待整合定名），至少有 `lastSafe{regionId,spawnId}`、`encounters.cleared`、`treasures`、`unlockedShortcuts`、`rewardReceipts`、`companion{companionId,discovered,collected,bondStage,appliedGrowthKeys}`。收據鍵為存檔槽／來源 ID／獎勵 ID。同一次世界存檔提交寫入收據、進度、回報與捷徑旗標，文件不得由多工作流直接各寫一半。確認提交才發 `EncounterCleared/RewardCommitted{encounterId,rewardId,firstClear}`。重載讀收據再補掛羈絆與 UI，避免雙給。提交失敗保留可重試結算及退出，無收據可重試該場。舊檔缺欄位用空紀錄及安全點，章節與英文進度保留。未知或損壞版本留原資料，只用隔離安全狀態恢復，不蓋掉舊檔。須測雙分頁競爭、寫入拒絕及領獎中斷，最後提交應在單一擁有者序列化。
- **動畫界線。** 保留核准的影空四向 Run／Idle、足點、轉場與相機。Attack、Dash 缺正式四向交付，North Cast 未可用。早期互動驗證可用腳底劍弧、閃避輪廓與風刃投射形狀。正式動畫與替代呈現須另做製作人逐格驗收，臨時效果不作為正式圖集核准。
