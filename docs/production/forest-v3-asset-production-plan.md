## 格式、來源及成本

原稿留在核准的私有美術來源，保留直通 alpha、作者、規格、固定雜湊和核准記錄。執行貼圖優先透明無損 WebP＋JSON。分頁留至少 4 px 邊緣延展和 4 px 間距，核對框內留白與影格鍵。「主圖核准 → 四向核准 → 動畫核准 → 實機載入核准」各自可退回。沒有已核准的疾風主圖。候選稿及偏差案例需記明，原稿不得當成執行批准。

無可比對的素材生成用量、單價或核准率足以估算本批成本，點數、金額及每件核准成本均為未知。保留既有免費本機處理，任何外部生成請求依「工作範圍、預算上限、嘗試次數」單項取得製作人核准。不得以規劃預算授權消費。
