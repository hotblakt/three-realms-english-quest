## 角色身份與參考審查

疾風是守在瀑布風口的白色風靈狐。牠警覺、好奇，以耳朵、視線與一聲短鈴邀影空靠近，主題是彼此建立信任。以正交斜俯視的日式動畫奇幻風格呈現，採乾淨剪影、少量色塊、左上冷漫光及偏灰藍的白毛陰影。停住時先抬耳，再側頭看向目標，緊張時收尾、伏耳。英文只出現在情境交流與簡短回應。

**待審原創造型。** 四足、尖耳、略短但仍尖的狐吻、單條蓬尾，避免幼兒化與犬形。以肩高為 1，耳尖高約 1.55，鼻至尾根長約 2.0，尾根至尾尖約 1.2，頭含吻長約 0.65。尾尖略上揚，尾巴約占側面全長三分之一。遊戲站姿耳尖到接地線先取影空**同鏡頭下實際可見身高**的 45–55%，從 50% 試起，縮放只在預覽調校，四向使用同一比例。

暖白主毛 `#F1F6FA`，陰影 `#A3B7CB`，青藍靈紋 `#54CDEB`，藍圍巾 `#326CAD`，金鈴 `#D9A84F`。前額一枚開口風旋、雙側肩胛短弧和尾根一條青藍弧，常態靠色塊辨識。金鈴懸於喉前，圍巾結固定在疾風自身左側，短尾布從左頸往後。青藍紋、圍巾和金鈴各有獨立輪廓。金鈴維持局部暖金，常態光暈關閉，戰鬥期間不與金色地面預警競爭。

## 四向與動畫交付

同一相機、同一比例與左上光，投影角度依專案美術指引。東西各自繪製並核對角色自身左右。四向都在實際 100% 遊戲尺度檢核深竹、淺霧與神龕陰影上的辨識度。[資產製作規格](../asset-production-guide.md) · [影空四向及足點驗收](../eiku-multidirection-actions.md)

| 方向 | 可讀特徵 |
| --- | --- |
| 南（鏡頭前） | 前額旋紋、對稱耳形、喉前鈴和左頸布結可讀，前掌落點清楚，尾巴錯位露在身後。 |
| 北（背向） | 後腦耳形、雙肩弧及尾根紋可讀。喉鈴由身體自然遮住，圍巾肩後的布尾仍可辨。 |
| 東（朝螢幕右） | 狐吻朝右、尾向左，以近遠前後足交替讀步態。依角色座標畫圍巾遠側結及前頸鈴。 |
| 西（朝螢幕左） | 狐吻朝左、尾向右，左側布結位於近側。前頸鈴、肩紋及尾根弧位置連續。 |

主稿單格至少 512 × 512 RGBA。P0 執行規格採 96 × 96 透明格，固定支撐原點 `(48,72)`（畫布左上為零），為四足支撐區中央在地平面的投影。畫布至少 4 px 透明留白。等比例全組縮放，保持落地與抬足差，不逐格重置到最低像素。腳點決定 Y 深度，和影空共用地面排序規則，同 Y 時以穩定的次序渲染。地影、風效及 UI 分層，淡化沿用場景遮擋規則。靈伴腳點與影空碰撞、互動區分離。

| 動作 | 每向規格 | 動作及轉換 |
| --- | --- | --- |
| 待機 | 6 格，6 fps，約 1 秒循環 | 四掌穩定、呼吸微動，耳尖及尾布有小幅延遲。偶發反應使用一格抬耳姿態和字幕，避免每循環響鈴。 |
| 小跑 | 8 格，12 fps，約 0.67 秒循環 | 對角前後足交替承重，第 0、4 格為相對的落地相位。尾和圍巾有慣性，鈴不離扣。世界位移由跟隨控制，補位可微調播放率，無額外高速圖集。 |
| 停步／轉向 | 由落地格接同向待機 | 位移停止即回待機，判向採主要位移軸，兩軸相等時保留上一個方向。四向切換沿用同一足點，禁止逐格縮放，步幅／動態之外的腳點誤差目標 ≤1 執行像素。 |
| 相遇、探索、戰鬥 | 重用四向待機及抬耳格 | 用面向、字幕、一次鈴聲或短亮紋表達。減少動態時使用靜態姿態及提示。音量為零仍可辨認。 |

總計 56 格。建議一頁 8 × 7、格距 100，約 800 × 700、2.14 MiB RGBA，額外 GPU／解碼尖峰需實測。交付透明 PNG＋JSON、可追溯主稿及審批狀態。影格鍵如 `hayate/south/idle/00`、`hayate/east/trot/07`，四向完整，無裁格旋轉及鏡像。驗收依序核對尺寸、鍵、透明邊、輪廓、循環、轉向接地、深度、手機記憶體與跟隨讀圖。選用圖集載入失敗時以核准靜態圖或文字呈現，並保持森林可操作；完整動畫驗收需實際素材。

## 初遇、英語、收集與成長

1. 在棲地安全互動區，玩家先聽鈴或看到短風痕。疾風朝玩家抬耳。沿用 E／觸控互動；只有玩家主動互動才打開交流。關閉、離場或切背景可從原地重開，戰鬥中暫停觸發。
2. 影空蹲下伸手。情境提示「邀牠一起走」，練習 **Come with me.**（跟我一起走吧。）提供文字、繁中提示、可選正常／慢速示範與 en-US 辨識。沿用現有練習的文字比對，接受相符後按繼續，或直接選「輔助練習」後繼續。拒絕麥克風、辨識失敗、離線或靜音時，保留可讀文字與輔助入口；辨識結果只用於文字比對。退出時釋放麥克風，語音與逐字稿不入存檔。現有課程與英文 EXP 維持原所有權，此句是否登錄為課程由整合決定。[現行英語練習](../../README.md#英語跟讀練習)
3. 疾風踏近並搖鈴，顯示「疾風加入同行」。確認後一次提交收集與羈絆首階進度，成功才呈現加入結果。已加入時重返棲地可重練短句，仍只保有同一隻疾風；重練及辨識升級不增加羈絆。
4. 羈絆 I「同行」開啟跟隨及情境提示。羈絆 II「風信」由本切片指定守護者首次通關獎勵確認後達成，顯示一次成長訊息並短亮尾紋。展示無額外攻擊倍率或數值差；回程可再看目前羈絆。若在尚未收集時已完成指定守護者，收集時依已保存的通關憑證補記一次，前置條件仍由 C 決定。

### 狀態與復原

持久欄位草案為 `schemaVersion`、`companionId=hayate`、`discovered`、`collected`、`bondStage`（0、1、2）及已套用的成長來源鍵。未遇見 → 已遇見未收集 → 已收集羈絆 I → 已收集羈絆 II，收集與成長只向前。跟隨、等待、戰鬥退到側邊、轉場待載入及提示冷卻為執行狀態，由讀檔時的場景與持久進度重建。舊存檔缺少欄位時以未遇見開始；資料錯誤時回安全檢查點並保留可驗證的已提交進度及既有章節、地圖和學習記錄，未知版本保留原資料供復原。整合審查選定存檔版本及落盤位置。

收集以 `companionId` 去重。成長以 C 的持久首次通關憑證去重（候選組合為 `companionId + encounterId + rewardId`）。收集或成長失敗時保留上一次已提交狀態。重試以來源鍵安全重播，載入及加入時用 C 的已提交紀錄補登漏掉的成長。C 保有戰利品發放，A 保有地標寶箱及捷徑狀態，疾風只記自身進度。

## 跟隨、探索與戰鬥行為

- **跟隨。** 追隨影空最近可通行的足跡，開闊地優先落在身後偏側，狹橋改為單列。起步距離先取 40、停步 26 世界單位形成遲滯，常速約為影空的 95%，拉遠補位上限 125%。疾風不阻擋影空、NPC 或橋口。方向以自身移動為主，停下保留面向，互動時朝玩家或提示目標。
- **等待及復位。** 互動、遮擋或路徑不通時停在最近安全腳點。距離超過 110 或連續 2 秒無有效路徑時，僅在同區已驗證落點且離開鏡頭時復位。鏡頭內沒有合法路徑就維持等待，直到可見的安全追趕或成功切區。跨區由 A 的出口與落點重建；失敗留在原區，死亡依 C 的安全檢查點重新佈位。場景未就緒時保持待載入，不使用舊區座標。
- **探索。** 瀑布側徑折返點附近提供一次提示。A 確認選定的區域、觸發帶、目標地標與圖示位置，且可走、未完成時，疾風停一步朝可走支口抬耳，顯示「疾風望向瀑布旁的小徑」。首次接近時提示一次，此地標每次進區僅提示一次，忽略或關閉後可依場景線索自行走。拾寶、開捷徑和解鎖判斷由世界處理。戰鬥、對話或轉場期間暫停自然提示。
- **戰鬥。** 守護者戰開始後退到 C 指定的安全側點，保持可能的預警形狀、觸控按鈕與影空動線可見；安全點不可用時收起場上表現。C 公布可反擊且風刃可用時，反擊期內提示「現在，試試風刃！」；同一遭遇嘗試只提示一次，逾窗立即消失。風刃尚未開放時顯示「現在可以反擊！」。鈴音只可出現在反擊窗，靜音保留文字。展示助攻是時機提示，命中、傷害、無敵、仇恨、冷卻與掉落均由 C 管理。先於棲地發生的戰鬥按原流程完成。
