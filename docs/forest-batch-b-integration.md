# 霧竹林 2.0｜批次 B 場景整合

以 `d59072175a3856223805cc21fb2c48a8f99468b5`（PR #31）為畫面基準。既有的 Batch B 準備提交 `a7352ad6de9e52576ddf06410667cef227d967f4` 已保留，離線 WebP 以 SHA-256 核對後直接沿用。來源審查與全部逐檔結果分別見 [素材準備報告](forest-batch-b-preparation.md) 與 [來源清單](forest-batch-b-provenance.json)。

## 場景配置

- 在 11 個既有竹叢足點交錯使用兩款竹幹和三款不同寬度與密度的竹冠。其餘竹叢保留既有圖像，讓林緣和林內的高度、密度及節奏有所不同。
- 選三處使用 `root-04`。根部與竹幹共用足點，以接地陰影連回地面，竹幹疊在平切根頂前。根、幹、冠在同一足點內依序繪製，葉面用獨立原點偏移。角色走到竹冠後方且上身進入覆蓋範圍時淡化，走到前方或離開覆蓋範圍時回復。透明度取決於位置，無需新增持續播放的 Tween。
- 苔石和落葉作不平鋪貼花，避開入口與主路中心，在寶箱路肩、溪岸外側和鳥居前做局部變化。濕地貼花在溪床與橋面之下，沿用 PR #31 水面、瀑布及岸礁。沿用原本所有碰撞足點和互動位置。
- 場景採用初審保留的九件，無新增淘汰。七件原本排除的素材保持排除。高光以既有左上方向為基準，沒有對新竹叢左右鏡像翻轉。

## 回歸紀錄

`npm ci`、正式建置、44 項 Node 測試及 7 項 Python 測試通過。新增自動測試涵蓋竹冠前後與兩側的透明度、抬高竹冠下方留空、既有遮擋行為，以及發布圖集的雜湊、留白與預算。Chromium 檢查四方向 Run／Idle、反覆切向、北向收步足點、近竹冠前後深度與淡化、溪岸碰撞、橋口、寶箱、神龕與返回捷徑。iPhone／iPad 橫向模擬驗證搖桿和減少動態。

正式建置的 GitHub Pages 子路徑也通過工作台往返、Batch B 圖集、四向必要動畫圖集與第一章進村的煙霧測試。

從重啟至通過場景與正式建置驗收共 227 秒。
